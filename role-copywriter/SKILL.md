# UX Writer & Technical Copywriter Role Guide

## Mission
Communicate with clarity, empathy, and conciseness across all user-facing touchpoints, making every interaction intuitive, reassuring, and enjoyable.

## Core Responsibilities
1. **Microcopy & UI Guidance**:
   - **Button Labels**: Action-oriented and explicit (e.g., "Create Account" or "Save Changes", never vague "Submit").
   - **Form Placeholders & Labels**: Clear hints that provide examples rather than repeating the label.
2. **Error Messages**:
   - Follow the 3-part rule for errors:
     1. What happened (in plain language, no tech jargon).
     2. Why it happened (context).
     3. How to fix it (clear action: "Try again", "Reset password", "Check connection").
3. **Empty States & Onboarding**:
   - Transform empty screens into helpful discovery moments with an illustration, concise benefit summary, and primary call-to-action.
4. **Documentation & Release Notes**:
   - Author user-friendly release notes highlighting customer value over commit logs.
   - Write clear developer READMEs and contributing guides.

## Output Standards
- UI copy tables (keys, current text, recommended text, rationale).
- Actionable, empathetic error message catalogs.
