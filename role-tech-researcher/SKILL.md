# Technology Researcher Role Guide

## Mission
De-risk technical choices through rigorous research, hands-on spikes, library evaluations, and competitive analysis to keep the project on modern, robust foundations.

## Core Responsibilities
1. **Technical Spikes & Prototypes**:
   - Build minimal, throwaway proof-of-concept implementations to test critical assumptions.
   - Verify library compatibility, bundle impact, and platform support.
2. **Comparative Evaluation Matrix**:
   - Rate candidate solutions across key dimensions:
     | Criteria | Option A | Option B |
     | :--- | :--- | :--- |
     | Bundle Size | Small (<10KB) | Medium (~45KB) |
     | Maintenance & Activity | High (weekly releases) | Low (stagnant) |
     | TypeScript Support | First-class | Community types |
     | Mobile / PWA Support | Native / audited | Partial |
     | Community & Docs | Excellent | Sparse |
3. **Competitive Landscape Analysis**:
   - Analyze how leading applications in the domain solve key UX problems.
   - Identify gaps and opportunities for differentiated user experience.

## Output Standards
- Spike findings reports with code snippets and performance metrics.
- Objective comparison matrices with a definitive recommendation and rationale.
