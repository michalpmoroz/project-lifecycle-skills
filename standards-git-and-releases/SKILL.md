# Git Conventions & Commit Message Standards

## Commit Title Rules
All commit titles must follow the [Conventional Commits v1.0.0](https://www.conventionalcommits.org/) syntax:

```text
<type>(<scope>): <short description in imperative present tense>
```

### Critical Rules:
1. **No Project Codenames in Title**: Never use project names or temporary codenames in the commit subject or type. Keep scopes functional (e.g. `pm`, `auth`, `api`, `ui`, `core`, `store`, `docs`, `ci`).
2. **Imperative, Lowercase**: Use `add`, `fix`, `update`, `remove` (not `added` or `adding`).
3. **Length**: Maximum 65 characters for the title line.

### Commit Types:
- `feat`: A new feature for users or administrators.
- `fix`: A bug fix or data correction.
- `docs`: Documentation additions or changes in `/docs/` or `README.md`.
- `chore`: Project management setup, tooling, CI, or dependency adjustments.
- `refactor`: Code reorganization with no change to behavior.
- `test`: Adding or correcting tests.
- `security`: Vulnerability fixes, sanitization, or permission hardening.

---

## Commit Body Rules
Every commit with significant changes must include a blank line after the title followed by an informative body:

```text
chore(pm): setup project management workflow and issue templates

- Add GitHub issue forms for features, bugs, tasks, and ADR proposals
- Add pull request template with archivist documentation checklist
- Define project label taxonomy and milestone rules
- Set up git commit conventions avoiding hardcoded project names

Closes #1
```

### What to include in the body:
- **Bullet points** summarizing key changes (added, changed, removed).
- **Rationale**: A brief explanation of *why* the change was made if not immediately obvious.
- **Task / Issue link**: Reference task number (e.g., `Closes #12`).

## Agent Co-Authorship & Attribution Policy
AI agents operating on this repository must strictly adhere to the project authorship rules:
- **Default**: Never append AI co-author trailers (e.g. Co-authored-by: Agent <bot@...> or Generated by ...) to commit messages or PR descriptions.
- **User Preference**: Only include AI co-authorship attribution if the user explicitly instructs to do so.
- **Initial Setup Inception**: On brand new repositories, the agent may ask the user during initial commit setup if they want AI attribution enabled, defaulting to **No** if unprompted or declined.
